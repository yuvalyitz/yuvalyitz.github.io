# Contributing

This repository contains Yuval Itzhaki’s personal website. Corrections to content and broken links are welcome through issues or pull requests.

Run the build and site checks described in README.md before submitting changes. Do not add credentials, private documents, original photo metadata, or local editor files.

Report problems in the upstream theme to [AcademicPages](https://github.com/academicpages/academicpages.github.io/issues).
